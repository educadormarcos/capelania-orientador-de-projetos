# Privacidade

## Escopo

O CapelanIA – Orientador de Projetos é um plugin baseado somente em skill. Ele não possui servidor próprio, API externa, banco de dados, sistema de autenticação, MCP ou conexão com serviços de terceiros.

A conversa acontece no ChatGPT da própria pessoa, conforme os termos e políticas aplicáveis à conta e ao produto utilizado. O Instituto Alfa e Ômega não recebe automaticamente o conteúdo das conversas realizadas com o plugin.

## Dados sensíveis

O plugin orienta o usuário a não inserir nomes reais, imagens, contatos, prontuários, relatos identificáveis ou outros dados pessoais desnecessários, especialmente de crianças e adolescentes. Exemplos e relatórios devem usar informações fictícias ou agregadas.

## Site institucional

O site https://iacapelania.oscalfaeomega.org é apenas institucional. Sua política publicada em https://iacapelania.oscalfaeomega.org/privacidade prevalece para eventual tratamento de dados realizado pelo próprio site.
